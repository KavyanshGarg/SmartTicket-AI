
# SmartTicket AI

An NLP-based customer support ticket classification application built using Python and machine learning.

## Features
- Classifies support tickets into Technical, Account, Billing, and General categories.
- Uses TF-IDF for text feature extraction.
- Uses Multinomial Naive Bayes for classification.
- Displays preliminary model evaluation metrics.
- Provides a simple interactive Streamlit interface.

## Technologies
Python, Pandas, Scikit-learn, TF-IDF, NLP, Streamlit.

## Installation
1. Clone or download this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

## Dataset and Evaluation
The project currently uses a small, manually created dataset.
The displayed test accuracy is preliminary and should not be
interpreted as evidence of real-world performance.
